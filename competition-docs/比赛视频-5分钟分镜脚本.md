# HydroGuardian比赛视频5分钟分镜脚本

## 制作口径

- 总时长：300秒。
- 叙事主线：现实问题—数据构建—五类专家—核心Agent—实验验证—Web与APP闭环—价值收束。
- 数据口径：两类基础数据与两类派生任务数据。
- 专家口径：GUFNet、RFANet、HydroProgram3D、Geometry Expert、Quality Verifier。
- Workflow由核心Agent按任务动态生成，不采用固定八阶段流程。
- 主案例统一为“识别河道附近新增的临时堆体，量测其空间范围，并生成现场核查任务”。
