# HydroGuardian 前端接口需求（按业务分类）

本目录用于沉淀**前端业务页面所需的后端接口草案**，每个业务目录下提供一个 `swagger.yaml`（OpenAPI 3.0）文件，便于：
- 后端实现前统一接口契约
- 前后端联调时对齐字段与分页/筛选参数
- 后续生成 API 文档或 SDK

## 总 Swagger

- `swagger.yaml`：合并后的总接口文件（包含 Bearer/JWT 鉴权与统一错误码规范）

## 目录索引

- `00-公共基础数据/swagger.yaml`
适用于前端基础下拉与关联数据：区域、模板、用户、角色、项目、数据集、样本。

- `01-首页与全局总览/swagger.yaml`
适用于首页/总览页：指标卡片、告警横幅、近期任务、风险分布、热力预览。

- `02-任务工作坊与执行监控/swagger.yaml`
适用于任务创建、任务查询、执行控制、日志流、结果查询。

- `03-风险分析区/swagger.yaml`
适用于风险事件列表与详情、风险图层、风险状态更新、工作区汇总。

- `04-工单中心/swagger.yaml`
适用于工单创建、查询、详情、状态流转、审核、时间线、附件上传。

- `05-历史回溯与对比/swagger.yaml`
适用于历史任务查询、回放详情、差异对比、时间窗口统计。

- `06-知识库与规则管理/swagger.yaml`
适用于规则与模板的 CRUD、发布与版本管理。

- `07-用户权限与系统设置/swagger.yaml`
适用于用户与角色权限、系统设置、系统健康、系统日志。

## 约定

- 统一前缀：`/api/v1`
- 统一返回：`code/message/traceId/data`
- 分页参数：`page`、`pageSize`
- 时间字段：ISO8601（如 `2026-05-26T10:00:00Z`）

> 说明：当前为需求草案，后续可根据后端落地方案调整路径、字段及鉴权方式。
