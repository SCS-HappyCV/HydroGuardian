# HydroGuardian 国自然式科学问题定位

## 前沿演进

1. 遥感视觉语言模型正在由场景分类、视觉问答发展到区域定位与细粒度语义理解，代表性工作包括 GeoChat、SkySense 和 GEOBench-VLM。
2. 地理空间智能体正在由模板化单任务调用发展到多工具、长链条空间分析，代表性工作包括 GeoLLM-Engine、ThinkGeo、OpenEarthAgent 和 GeoAgentBench。
3. 三维语言理解正在由对象级问答发展到语言引导分割和复杂空间推理，代表性工作包括 GPT4Point、SegPoint、R2S 等。
4. 最新研究开始强调地理空间 Agent 的结构化状态、物理有效性、运行时反馈和 verifier-guided execution，说明“能调用工具”正在向“可验证执行”演进。

## 现有研究的三层断裂

### 断裂一：语义理解与工程任务之间

现有遥感大模型擅长回答“图中有什么”，但水利巡查需要把“查找坝脚附近疑似新增扰动并判断是否需要现场复核”等隐含意图转化为目标对象、空间关系、时间对照、精度要求和处置约束。

### 断裂二：多模态感知与动态专家协同之间

影像、双时相变化、点云语义和几何关系具有不同的数据结构、误差来源和尺度。现有方法多在单一模态或固定任务上优化，尚未解决复杂任务下专家选择、依赖生成、产物引用和误差传播的统一表达问题。

### 断裂三：算法结果与可信风险证据之间

模型置信度不能等同于工程可信度。变化掩膜、点云标签和语言定位结果必须同时满足数据完整性、空间一致性、时间可比性、物理合理性和来源可追溯性，才能进入风险研判与人工复核。

## 核心科学问题

在风险目标稀疏、观测模态异构、任务语义隐含且工程判据强约束的水利巡查环境中，如何建立自然语言意图、多模态专家能力与工程风险证据之间的动态映射关系，并通过验证反馈抑制多步执行中的空间、时间和物理不一致，使 Agent 形成可校验、可溯源、可转化的风险认知？

## 拟形成的三个研究目标

1. 揭示隐含巡查意图向结构化工程任务迁移的表达机制，建立任务语义、观测模态、空间约束和专家能力之间的可计算映射。
2. 研究异构专家动态协同过程中的依赖生成与证据传播机制，保持多步骤执行中的空间、时间与语义一致性。
3. 研究面向工程风险的验证反馈和不确定性传递机制，使算法产物能够转化为具有质量边界、来源链和人工复核条件的证据对象。

## 立项依据的叙事主线

工程安全需求不是起点的终点，而是提出科学问题的场景载体。正文应按以下逻辑展开：

水利工程风险认知的特殊性 → 遥感多模态智能理解前沿 → 工具型 Agent 的最新进展 → 三类现有断裂 → 核心科学问题 → 项目研究假设 → 前期工作如何证明可行 → 预期形成的新机制与新范式。

不能继续采用“政策要求—行业痛点—系统功能—部署现状”的说明书逻辑，也不能把 PostgreSQL、RabbitMQ、MinIO、SSE 等工程组件放在立项依据主体中。
